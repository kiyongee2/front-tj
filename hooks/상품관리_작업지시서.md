# 📦 상품 관리 시스템 - 작업지시서

## 📋 개요
React의 `useState` 훅을 활용한 상품 추가, 삭제, 목록 관리 시스템

---

## 🎯 주요 기능

### 1. 상품 추가 (Add Product)
- **입력 값**: 상품명 (text input)
- **유효성 검사**: 빈 값 입력 방지
- **고유 ID**: `Date.now()`를 사용하여 자동 생성
- **동작**: 입력 후 "추가" 버튼 클릭 시 상품 목록에 추가
- **결과**: 콘솔에 현재 상품 목록 배열 출력

### 2. 상품 목록 표시 (Product List Display)
- **형식**: 비순차 리스트 (`<ul>`)
- **표시 내용**: 상품명 + 삭제 버튼
- **빈 목록 처리**: "추가된 상품이 없습니다." 메시지 표시

### 3. 상품 삭제 (Delete Product)
- **방법**: 각 상품 항목의 "삭제" 버튼 클릭
- **동작**: `filter()` 메서드로 해당 상품만 제외
- **결과**: 콘솔에 업데이트된 상품 목록 배열 출력

---

## 🔧 상태 관리 (State Management)

### productName
```javascript
const [productName, setProductName] = useState('');
```
- **용도**: 입력 필드의 현재 값 관리
- **초기값**: 빈 문자열
- **업데이트**: 입력 변화 시 또는 상품 추가 후 초기화

### products
```javascript
const [products, setProducts] = useState([]);
```
- **용도**: 상품 목록 배열 관리
- **구조**: `[{ id: number, name: string }, ...]`
- **초기값**: 빈 배열

---

## 📝 함수별 상세 설명

### handleInputChange(event)
```
목적: 입력 필드에서 사용자 입력 감지
동작: event.target.value를 productName 상태로 업데이트
```

### handleAddProduct()
```
목적: 새 상품을 목록에 추가
전제조건: productName이 빈 값이 아님 (검증)
동작:
  1. productName이 비어있으면 alert 표시 및 함수 종료
  2. 새로운 상품 객체 생성: { id, name }
  3. 기존 products 배열에 새 상품 추가
  4. 콘솔에 상품 목록 출력
  5. productName 입력 필드 초기화
```

### handleDeleteProduct(id)
```
목적: 특정 ID의 상품을 목록에서 제거
동작:
  1. id를 기준으로 해당 상품 필터링
  2. 새로운 배열로 products 상태 업데이트
  3. 콘솔에 업데이트된 상품 목록 출력
```

2. **배열 불변성**: 새로운 배열을 생성하고 전개 연산자(`...`) 사용

## ✅ 실행 순서 (Workflow)

1. 사용자가 입력 필드에 상품명 입력
2. `handleInputChange()` 실행 → `productName` 상태 업데이트
3. "추가" 버튼 클릭
4. `handleAddProduct()` 실행:
   - 입력값 검증
   - 새 상품 객체 생성
   - `products` 상태에 추가
   - 콘솔 출력
   - 입력 필드 초기화
5. 화면의 상품 목록 자동 업데이트 (re-render)
6. (선택) 삭제 버튼 클릭 → `handleDeleteProduct()` 실행
