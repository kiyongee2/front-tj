변수와 자료형

자바스크립트에서 변수는 데이터를 저장하는 공간입니다. 변수를 선언할 때는 var, let, 또는 const 키워드를 사용할 수 있습니다.

변수 선언


    var name = "Alice"; // var로 변수 선언
    let age = 30; // let으로 변수 선언
    const PI = 3.14; // const로 상수 선언

자료형

자바스크립트에는 여러 가지 자료형이 있습니다. 주요 자료형은 다음과 같습니다:

  • String: 문자열을 나타냅니다. 예: "Hello, World!"
  • Number: 숫자를 나타냅니다. 예: 42, 3.14
  • Boolean: 참(true) 또는 거짓(false)을 나타냅니다. 예: true, false
  • Null: 의도적으로 값이 없음을 나타냅니다. 예: null
  • Undefined: 값이 할당되지 않은 변수를 나타냅니다. 예: undefined
  • Object: 객체를 나타냅니다. 예: { name: "Alice", age: 30 }
  • Symbol: 고유한 식별자를 나타냅니다. 예: Symbol("id")
